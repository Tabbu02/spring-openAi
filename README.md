# Spring AI Chatbot with Ollama + Phi-3

A Spring Boot application that integrates with Ollama to run Microsoft Phi-3 model locally. No API key, No internet needed for chat!

## 🚀 Tech Stack
- Java: 17
- Framework: Spring Boot 3.2.x
- Spring AI: For LLM integration
- AI Model: Ollama + Microsoft Phi-3 Mini
- Build Tool: Maven

## ✨ Features
- Chat with local LLM using Ollama + Phi-3
- Spring AI integration with REST API
- 100% Local & Private - Data never leaves your laptop
- Lightweight - Phi-3 runs even on 8GB RAM
- REST API for chat: POST /api/chat

## 🛠️ How to Run

### 1. Install Ollama
Download from: https://ollama.ai

### 2. Pull Phi-3 Model
```bash
ollama pull phi3
```

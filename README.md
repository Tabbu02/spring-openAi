# Spring AI Chatbot with Ollama

A Spring Boot application that integrates with Ollama to provide a local AI chatbot. No OpenAI API key needed!

## Tech Stack
- Java: 17
- Framework: Spring Boot 3.x
- AI: Ollama (Local LLM)
- Build Tool: Maven

## Features
- Chat with local LLM using Ollama
- Spring AI integration
- REST API for chat
- Runs 100% locally

## How to Run
1. Install Ollama from https://ollama.ai
2. Pull a model: ollama pull llama3
3. Run the Spring Boot app: 
```bash
mvn spring-boot:run
```
